# 태그 기능 정의서 (확정본)

> 원본(`spec-original.md`)을 질의응답으로 구체화한 확정 스펙

## 기능 개요

노트에 태그를 추가하고 관리할 수 있다.

## 기능 요구사항

- 노트에 태그를 추가할 수 있다
- 노트에 추가된 태그를 삭제할 수 있다
- 태그 목록을 노트 상세 화면(에디터)에서 확인할 수 있다

## 데이터 구조

- `Note`에 `tags: string[]` 필수 필드를 추가한다
- 태그는 문자열로 저장한다
- `db.json`의 기존 노트 4건에 `"tags": []`를 추가한다 (의도된 시드 변경)
- 신규 노트 생성 시에도 `tags`를 함께 전달한다 (`addNote(title, content, tags)`)

## 태그 규칙

| 항목             | 규칙                                               |
| ---------------- | -------------------------------------------------- |
| 정규화           | 앞뒤 공백 제거(trim), 선행 `#` 제거                |
| 빈 문자열        | 무시 (추가하지 않음)                               |
| 중복 판정        | trim 후 **대소문자 무시** 비교 (`React` = `react`) |
| 저장 표기        | 사용자가 입력한 대소문자 그대로 유지               |
| 태그당 최대 길이 | 20자                                               |
| 노트당 최대 개수 | 10개                                               |
| 제한 초과/중복   | 추가를 차단하고 안내 메시지 표시 (입력값은 유지)   |

> 길이/개수 제한은 상수(`MAX_TAG_LENGTH`, `MAX_TAG_COUNT`)로 분리해 조정 가능하게 한다.

## UI 패턴

- 위치: `NoteEditor` 안, 내용 입력과 버튼 영역 사이
- 입력: 태그 입력창에서 **Enter 또는 쉼표(`,`)** 로 칩 추가
- 삭제: 각 칩의 **× 버튼**
- 한글 IME 조합 중(`isComposing`)에는 Enter를 제출로 처리하지 않는다
- 표시 범위: **상세(에디터)에서만 표시**. 목록(`NoteList`/`NoteItem`)은 변경하지 않는다
- 반응형: 칩은 줄바꿈(`flex-wrap`), 긴 태그는 `truncate`
- 접근성
  - 입력창에 `label` 제공
  - 칩 목록은 `ul/li` 시맨틱 사용
  - × 버튼에 `aria-label="{태그} 태그 삭제"`, 키보드 포커스/조작 가능
  - 오류 메시지는 `role="alert"`

## 저장 시점

- 태그는 `NoteEditor`의 로컬 state로 관리한다 (제목/내용과 동일)
- 기존 **"저장" 버튼**을 눌러야 제목/내용/태그가 한 번에 서버에 반영된다 (1회 PATCH/POST)
- "취소" 시 태그 변경도 반영되지 않는다
- 노트 선택이 바뀌거나 새 노트 작성 시작 시 태그 state를 해당 노트 값(신규는 `[]`)으로 동기화한다

## 범위 외 (이번 단계에서 하지 않음)

- 목록 카드의 태그 표시
- 태그 기반 필터/검색
- 쉼표가 포함된 문자열 붙여넣기 일괄 분리
- Backspace로 마지막 칩 삭제

## 비고

- 원본 비고 유지: 태그는 문자열로 저장, 중복 태그는 허용하지 않음
- 선행 `#` 제거와 빈 문자열 무시는 별도 답변 없이 제안값으로 확정한 항목이다
